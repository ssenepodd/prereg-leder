# 사전공개 원장

투자 판단을 **결과가 나오기 전에** 기록하고, **결과가 나오면 기계가 판정을 붙이는** 공개 원장.

이건 추천이 아니다. 종목을 권하지 않고, 수익을 인증하지 않는다.
기록하는 것은 하나다 — **무엇을 주장했고, 무엇이 관측되면 틀린 것이며, 실제로 어떻게 됐는가.**

---

## 규칙 6건

원장의 값은 규칙의 강제 방식에서 나온다. 아래는 지키겠다는 다짐이 아니라 **어기기 어렵게 만든 장치**다.

| # | 규칙 | 어떻게 강제되나 |
|---|---|---|
| 1 | 선택한 공개 수준 안에서는 **전량**을 싣는다. 선별하지 않는다 | `validate.py` — 논지 없는 포지션, 미등록 논지 참조를 막는다 |
| 2 | **결과는 사람이 쓰지 않는다.** 성숙일에 잡이 판정한다 | `outcomes/` 는 봇 커밋만 쓴다. 사람 커밋과 서명으로 구분된다 |
| 3 | **금액을 싣지 않는다.** 비중(%)만 | `validate.py` — 금액성 필드·금액으로 보이는 값을 막는다 |
| 4 | **회차를 수정·삭제하지 않는다** | `main` 브랜치 보호로 force-push 차단. 정정은 새 회차로만 |
| 5 | **회차마다 OpenTimestamps 스탬프** | `stamp.sh`. 검증은 아래 「이 원장을 검증하는 법」 |
| 6 | 원장 외의 것을 이 리포에 두지 않는다 | 이 리포에는 원장만 있다 |

### 공개 수준

| 수준 | 공개 내용 |
|---|---|
| **L1** | 논지 · 반증조건 · 평가일 · 판정 |
| L2 | 위 + 보유 종목 · 비중(%) · 회전율 집계 |
| L3 | 위 + 벤치마크 대비 상대수익률 |

수준은 **미리 선언되고 모든 회차에 균일하게** 적용된다. 회차마다 결과를 보고 고르는 것은
선별이며 규칙 1 위반이다. **수준은 올릴 수만 있고 내릴 수 없다.**

아직 공개하지 않는 수준의 회차도 같은 시점에 작성해 `hashes/` 에 **해시만** 박아 둔다.
따라서 나중에 일부만 공개하면 **빠진 회차가 해시로 드러난다** — 좋은 달만 골라 여는 것이 불가능하다.

## 이 원장을 검증하는 법

원장을 믿을 이유는 작성자의 성품이 아니라 **확인 가능성**이어야 한다. 세 가지를 직접 확인할 수 있다.

**① 그때 썼는가** — 커밋 날짜는 위조 가능하다(`--date`, `GIT_COMMITTER_DATE`). 그래서 별도 앵커를 쓴다.

```bash
pip install opentimestamps-client
ots verify entries/2026-09.md.ots        # 비트코인 블록 시각으로 확인된다
```

**② 안 고쳤는가** — `main` 은 force-push 가 차단돼 있다. 회차 파일의 전체 이력:

```bash
git log --follow --patch entries/2026-09.md
```

**③ 다 실었는가** — 미공개 수준의 해시가 매달 박혀 있다. 나중에 원문이 공개되면 대조한다:

```bash
sha256sum full_2026-09.md          # hashes/2026-09.sha256 과 일치해야 한다
```

## 구조

```
entries/YYYY-MM.md        회차 — 논지·반증조건·평가일 (사람이 쓴다)
entries/*.ots             OpenTimestamps 증명
outcomes/<thesis_id>.yaml 판정 — 성숙일에 ★잡이 쓴다★
hashes/YYYY-MM.sha256     미공개 수준의 해시
rollup.md                 전 회차 집계 (자동)
validate.py               형식 검증기
```

### 판정은 두 축으로 잰다

|  | 주가 반영 | 주가 미반영 |
|---|---|---|
| **논지 채택** | 맞고 벌었다 | **맞았는데 못 벌었다** |
| **논지 기각** | **틀렸는데 벌었다** | 틀리고 잃었다 |

한 칸으로 합치면 두 대각선이 사라진다. **"틀렸는데 벌었다"** 는 운을 실력으로 오인하게 만드는
가장 위험한 칸이라 반드시 기록한다. `판정불가` 도 1급 판정이며, 그 비율은 숨길 지표가 아니라
반증 가능한 문장을 쓰고 있는지를 재는 메타 지표다.

## 쓰는 법

```bash
cp entries/_TEMPLATE.md entries/2026-09.md
$EDITOR entries/2026-09.md            # 논지·반증조건·평가일. FALSIFIER-GUIDE.md 를 먼저 읽을 것
python3 validate.py entries/2026-09.md
./stamp.sh entries/2026-09.md         # 검증 통과 시 커밋 + OTS 스탬프
git push
```

반증조건 쓰는 법은 **[FALSIFIER-GUIDE.md](FALSIFIER-GUIDE.md)** 에 있다. 첫 회차에서 어려운 건
포지션 나열이 아니라 이쪽이다.

---

## 면책

이 원장은 작성자 본인의 판단과 그 결과에 대한 기록이다.
특정 종목의 매수·매도를 권유하지 않으며, 어떠한 대가도 받지 않는다.
투자 판단과 그 결과는 각자에게 귀속된다.
